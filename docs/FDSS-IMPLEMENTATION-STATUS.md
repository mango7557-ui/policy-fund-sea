# 바른자금 설계 반영 현황

기준: 통합설계서 v4.0(2026-11-13), 기술기업·성장성·자금수요 심화진단 v4.2 및 사용자 제공 AI 운영 원칙.

## 현재 제공

- 직접 입력에 기반한 기본 질문과 규칙 기반 사전 안내. 입력값은 증빙 검증값이 아니다.
- 선택형 3개년 자금수요 개략 계산: 시설, 운전자본, R&D, 경상비 증가, 채무 만기 대응에서 중복을 제거하고 내부창출, 확정 투자·지원금, 자체자금을 차감한다. 같은 3년 기간의 합계이며 승인액·조달한도가 아니다.
- 기술·제조·벤처·R&D 또는 대규모 시설·투자 계획을 선택할 때만 사업화 단계와 근거자료 보유 여부를 묻는다. 위험 상황을 직접 선택하면 전문가 검토 필요를 안내한다. 이는 실제 자료검증이나 전문가 연결이 아니다.
- 자료의 출처, 검증 전 상태, 기관 심사와 플랫폼 판단의 차이를 화면에 표시한다.
- 외부 AI 연결이 없을 때는 규칙 및 문서 검색 기반 응답을 사용한다.

## 구현 및 운영 조건이 필요한 항목

- NICE D&B 및 공공·금융 API: 계약, 제공 범위, 목적별 동의, 권한·저장·재제공 조건 확인과 서버 연계 필요. 현재 연결되지 않았다.
- 기술·시장·사업화의 증빙 기반 심화진단, 자료 충돌·불충분 시 전문가 검토 게이트, 12대 자금원, Hard/Soft Rule, 검증된 추천·비추천과 신뢰도: 실제 데이터 및 규칙 검증을 거쳐 구현해야 한다. 현재 계산기는 해당 엔진이 아니다.
- OCR·파일 업로드, 안전한 계정·접근통제·감사기록, 결제, 유료 보고서 발행, 전문가 배정·검토, 상담 예약·사후관리와 민원 처리: 운영 시스템 및 검수 절차가 필요하며 현재 제공되지 않는다.
- 생성형 AI는 승인·등급 결정자가 아니다. 실제 서비스화에는 검증된 FDSS 결과를 구조화해 AI에 전달하고, AI 결과가 판단을 변경하지 않는 검증 경계가 필요하다.
- 신용정보·재무정보를 포함한 외부 서비스 전송 및 저장의 동의, 보안, 계약과 법률 검토는 별도 완성 전까지 상용 서비스의 요건 충족으로 간주하지 않는다.
